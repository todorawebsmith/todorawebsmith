## `// who we are`

**Todora Websmith** adalah web development studio berbasis di Bali yang berfokus membangun sistem digital yang **terstruktur, scalable, dan relevan jangka panjang**.

Kami percaya bahwa website bukan sekadar tampilan — melainkan **infrastruktur bisnis** yang harus dirancang dengan benar sejak awal. Setiap keputusan arsitektur, setiap baris kode, dan setiap komponen UI yang kami buat memiliki satu tujuan:

> **Sistem yang tetap bekerja dengan baik saat bisnis Anda berkembang.**

---

## `// core principles`

```
STRUCTURE FIRST    →  Arsitektur dirancang matang sebelum baris kode pertama ditulis
SCALABLE BY DESIGN →  Sistem dibangun untuk berkembang, bukan sekadar berjalan
BUSINESS-ORIENTED  →  Setiap keputusan teknis punya alasan bisnis yang konkret
LONG-TERM THINKING →  Durability dan maintainability lebih penting dari kecepatan delivery
```

## `// workflow`

```mermaid
graph LR
    A[Discovery] --> B[Planning]
    B --> C[Development]
    C --> D[Testing]
    D --> E[Delivery]
    E --> F[Support]

    style A fill:#0d1b3e,stroke:#3b5998,color:#e8e8f0
    style B fill:#0d1b3e,stroke:#3b5998,color:#e8e8f0
    style C fill:#0d1b3e,stroke:#3b5998,color:#e8e8f0
    style D fill:#0d1b3e,stroke:#3b5998,color:#e8e8f0
    style E fill:#0d1b3e,stroke:#3b5998,color:#e8e8f0
    style F fill:#0d1b3e,stroke:#3b5998,color:#e8e8f0
```

| `#` | Phase | What happens |
|:---:|:---|:---|
| `01` | **Discovery** | Mendalami bisnis, target pengguna, dan kebutuhan nyata klien |
| `02` | **Planning** | Merancang arsitektur sistem & user flow sebelum coding dimulai |
| `03` | **Development** | Implementasi dengan standar kode bersih dan terdokumentasi |
| `04` | **Testing** | Quality assurance — fungsionalitas, performa, dan responsivitas |
| `05` | **Delivery** | Serah terima dengan dokumentasi teknis lengkap |
| `06` | **Support** | Maintenance berkelanjutan & scaling seiring pertumbuhan bisnis |
